# qrcode-ai-com.github.io

The publisher site of the open-source QR Code & Barcode Scanner by QR Code AI, to be served by
GitHub Pages at <https://qrcode-ai-com.github.io/>.

This first commit holds only this README and a placeholder page. The site's pages are generated
from the engine repository, <https://github.com/qrcode-ai-com/qrcode-barcode-scanner-rust>
(`distribution/publisher`), and arrive here through a reviewed pull request. Nothing in this
repository is meant to be edited by hand.
